Policy and lock

Both files are YAML with version: "1.0". Unknown keys are rejected. The JSON Schemas live in schemas/ in the repository. A worked policy is examples/policy.yaml.

policy.yaml

  • languages — python, typescript, javascript, go, rust, java, kotlin. Default is python and typescript.
  • complexity_caps — positive integers. apply_to must be added_or_modified_functions.
  • mutation_gate.incremental_only must be true. tier3_gates must be false. Kill rates are 1 to 100. max_mutants defaults to 200. timeout_seconds defaults to 30. test_command is an argv list.
  • review_triage.allow_remote_model must be false. max_inline_comments is 1 to 5. sandbox is worktree or docker.
  • comprehension_gate weights are fixed at 0.25, 0.20, 0.35, and 0.20. risk_threshold is 1 to 100, default 60.

Several integers treat 0 as "use the default", so a threshold of 0 cannot be stored. Use 1 when you want the gate to be strict.

scope.lock.yaml

proofsieve lock writes this file. change_type is bugfix, feature, or refactor. max_files and max_loc_delta must be positive. Lock globs that match nothing are an error. Each locked file records a 64-character lowercase SHA-256. The command always inserts a deny for .proofsieve/**.

Attestation comment

/proofsieve attest
sha: <head>
spec: REQ-1
invariant: <at least 10 characters>
failure: <at least 10 characters>
test: test_price

spec may be specs/price.md#REQ-1. The id is the text after the last #. A bare path or a markdown filename without an id is rejected.
