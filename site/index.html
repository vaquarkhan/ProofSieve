Probabilistic generation. Deterministic verification. Human-owned code.

ProofSieve is the control plane for AI-assisted coding. Agents may type. They do not decide scope, grade their own tests, or merge a change nobody can explain.

A local hook denies writes that leave the scope lock. proofsieve check in CI is the merge authority, because a hook can be bypassed. Exit codes are 0 pass, 1 policy failure, and 2 configuration or infrastructure failure. The guard uses 0 to allow a tool call and 2 to deny it.

Four gates

  1. Scope lock — file count, churn, denied paths, and locked human tests.
  2. Test oracle — diff-scoped mutation against a command you supply. The agent does not write the oracle.
  3. Proof-gated review — a finding is kept only when a named test passes on the base and fails on the head, or when it arrives as SARIF.
  4. Human ownership — a risk score above the threshold requires a /proofsieve attest comment from a human account.

Install

go install github.com/vaquarkhan/ProofSieve/cmd/proofsieve@latest

Requires Go 1.23 or newer. The module does not use cgo. Start with the tutorial.
