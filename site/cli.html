CLI

proofsieve help prints the same summary. --repo defaults to the working directory.

CommandPurpose
initWrite policy and editor hooks if they are missing.
lock --spec --allowWrite the scope lock. Repeat --allow, --deny, and --lock-glob. --change-type is bugfix, feature, or refactor.
guardRead one hook payload on stdin. Print a JSON decision. Exit 0 or 2.
check --baseRun the gates from base to --head (default HEAD).
mutate --baseRun only the mutation gate and write surviving_mutants.json.
test-gen --spec --src --outStrip function bodies into a clean-room bundle. This is not a merge gate. A leaked body exits 1.
verify-findings --input --baseReproduce review claims and write the kept set.
attestPrint a comment, or attest verify a saved comment.
versionPrint proofsieve 1.0.0.

check flags

  • --format md|json|sarif
  • --gate all|scope|complexity|mutation|review|ownership
  • --policy and --lock override the default paths under .proofsieve
  • --attest-file and --attest-author supply the human comment
  • --evidence writes the JSON report to a file as well as stdout

Exit codes

For check, mutate, and verify-findings: 0 pass, 1 policy failure, 2 usage or infrastructure. guard is only 0 or 2. Usage errors, including an unknown command, exit 2.
