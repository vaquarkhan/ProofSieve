Developer guide

The module is github.com/vaquarkhan/ProofSieve. Go 1.23. The only third-party dependency is gopkg.in/yaml.v3. Tests use the real git binary and temporary repositories. On Windows, those repositories set core.autocrlf to false and commit.gpgsign to false so byte comparisons stay stable.

Package map

PackageRole
cmd/proofsieveProcess entry. main calls cli.Execute.
internal/cliFlag parsing and exit codes.
internal/guardHook payload, session budget, deny or allow.
internal/checkAuthoritative gate runner over git diff.
internal/policy, lockfile, scopeConfiguration and path decisions.
internal/langPython and C-like lexers, cognitive complexity.
internal/mutateIn-process mutants and a copied tree.
internal/reviewSARIF, reproduction, the comment cap.
internal/attest, riskHuman comment and the risk score.

Tests and coverage

go test ./... -count=1 -coverprofile=cover.out -covermode=atomic
go tool cover -func=cover.out

CI requires the total line to read 100.0%. Add a test in the same package when you add a branch. Infrastructure errors that the operating system will not produce in a unit test are reached through a package-level function variable that production code sets to the real function.

Adding a language

Return the language id from lang.Language, implement tokenization and Analyze, and mark it supported only when both exist. A recognized language without an analyzer must fail the complexity gate rather than pass. Mutation operators live in internal/mutate and should no-op for languages they do not understand.

Threat model

The hook is best-effort and same-turn. Native editor writes that skip the hook are caught by CI. Test names are not passed to a shell. Mutation and review commands are argv lists. Docker reproduction, when selected, uses --network=none and --read-only. Remote model review is rejected by policy. Bot accounts cannot satisfy attestation. The agent cannot edit .proofsieve through the hook.

The longer design notes are in docs/ARCHITECTURE.md, docs/REQUIREMENTS.md, and docs/DEVELOPMENT.md in the repository.
